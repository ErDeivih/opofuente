**tres supuestos generados y guardados por 0,30 $**.

## Lo que se rompe si cambias X

- **si se baja el 90 %**: entran supuestos cuyas respuestas dos modelos no comparten;
- **si se arregla un supuesto rechazado**: deja de ser prueba de si el temario tiene respuestas defendibles;
- **si se acepta una indicacion sin apartado**: un aviso sobre un parrafo reescribe el tema entero;
- **si el alta adivina el esquema**: cada `IntegrityError` cuesta una ronda —**paso cinco veces**—.
